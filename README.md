# 🚔 Crime Data Analysis Dashboard

An interactive web-based dashboard designed to analyze and visualize crime data through dynamic charts, heatmaps, filters, and incident reports. The dashboard helps identify crime patterns, monitor district-wise activity, and generate actionable insights for law enforcement and public safety analysis.

## ✨ Features

- Interactive dashboard with real-time filtering
- Crime trend analysis across months and years
- District-wise crime distribution
- Crime category breakdown using charts
- Severity analysis (High, Medium, Low)
- Activity heatmaps by time and day
- Incident management table with search and sorting
- Key insights and hotspot identification
- Responsive modern UI design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Responsive Web Design

## 📊 Dashboard Modules

### Crime Overview
- Total incidents
- Solved cases
- Solve rate
- Monthly averages
- Peak crime districts

### Visual Analytics
- Monthly trend charts
- Crime type distribution
- District comparison charts
- Severity analysis

### Operational Insights
- Crime hotspot detection
- Peak activity periods
- Solve-rate comparison
- Resource allocation recommendations

### Incident Log
- Searchable records
- Severity classification
- Status tracking
- Officer assignments

## 🎯 Project Objectives

- Transform raw crime data into actionable insights
- Improve crime pattern recognition
- Support data-driven decision making
- Demonstrate frontend data visualization skills
